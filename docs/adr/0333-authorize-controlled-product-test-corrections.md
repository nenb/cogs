## Required correction contracts

1. **Host-published read-only skills.** A fresh root-owned `0700` run root separates unmounted `control/` from `publication/<gen>/{shared,user}/<bundle-hex>`, workspace, and worker state. Descriptor-relative host custody resolves exact OCI/user bundles, discovers skills, exclusively stages ordinary paired trees, validates canonical inventories/modes/sizes/hashes/EOF, fsyncs bottom-up, and publishes by no-replace rename plus parent fsync and exact durable readback. Never adopt foreign destinations. Mount only the two exact publication subtrees RO with private propagation and no containing-directory/writable alias. Start sandbox with `--cap-drop ALL` and only measured `{CHOWN,DAC_OVERRIDE,FOWNER,SETGID,SETUID,KILL,NET_BIND_SERVICE,SYS_CHROOT}`; preserve `no-new-privileges`, production seccomp, and sshd privilege separation. No `SYS_ADMIN`, `NET_ADMIN`, `NET_RAW`, `MKNOD`, or `SETPCAP`. Authenticate complete mounts, device/inode identities, live mount namespace, capability masks, image/container IDs and `RW=false` before SSH. Measure authenticated SSH/SFTP with the exact set and removal of each required capability; unexpected effective capability rejects. Guest write/chmod/rename/unlink tests are supplemental only.

   Production defaults to a separate SFTP verify-only preparer: bounded stable observations reject missing/extra/duplicate/symlink/special-bit/wrong-mode/size/hash content, and verify the same retained canonical bundles used by host Pi. It never mkdirs, writes, renames, chmods, or unlinks. A durable supervisor receipt binds version, generation, exact worker/sandbox IDs, mount namespace, both source device/inodes, destinations, RO flags, bundle digests and consumer ID. Bounded no-follow trusted-file capture plus a one-time nonce over an authenticated live Unix channel establishes lease authority; SFTP or TypeScript branding cannot mint `readOnlyEnforced: true`. Missing receipt/transport fails startup; disposal releases the lease without deleting publication. The old mutating preparer remains only for explicitly injected non-production callers, with no production fallback.

2. **Bounded event protocol.** Admit raw Pi callback values before reading `event.type`, observing models, Git binding, telemetry, or sanitizers. Reject proxies with `node:util.types.isProxy` before reflection; read only known own data descriptors and bounded array indices. No arbitrary enumeration, getters, `toJSON`, giant stringify, or double `sanitizeJson`. Give telemetry/Git separate admitted projections. `ApiServer.publish(): boolean` means accepted into bounded replay, not subscriber delivery: complete/omitted acceptance is true; invalid/unavailable/poisoned/sequence-exhausted publication stays false and fatal at every consumer; backpressure disconnects only that subscriber.

   Use a closed envelope and subtype schemas with codec-owned `payload.cogs_transport`, version `cogs.event-detail/v1`, status `complete|omitted`, and a closed reason. Preserve mandatory terminal/status/correlation/request/tool identity/error, settled/aborted/shutdown, Git/checkpoint trust and complete S3 proof fields. Overlong mandatory IDs are invalid, not clipped successes; optional detail is omitted as whole units. Redact once before omission. No invented durable digest/history reference. Default frame 32 KiB, configuration 4096 bytes..1 MiB; maximum mandatory fixtures prove <=3072 payload and <=4096 framed bytes. Bound depth 16, nodes 2048, entries 128, encoded-input admission 1 MiB, and redaction/work. Sequence advances once after the exact frame is built. Update all application consumers and the launcher parser; preserve separate SSH bash-update and history/fragment contracts; claim no replay reliability.

3. **Earliest production zero-integration rejection.** Reject `integrations: []` immediately after validated runtime/launch reads and before secret reads, snapshots, telemetry, storage, SSH, auth, egress, Pi, or API acquisition. Keep shared launch schema unchanged because lower-level route/Pi/lifecycle fixtures deliberately admit empty plans. Add closed production-only semantic admission plus defensive manager checks; schema-valid does not mean production-admissible. Never insert a dummy integration.

Do not freeze global fetch, relax TLS, change timeout/cooldown/retirement/accounting, or make telemetry authoritative. Separately test default real bounded development loopback HTTP, shared transport negatives, and production composition using a generated exact-loopback-SAN HTTPS certificate with trust fixed before worker initialization. Canonical production runtime documents have HTTPS trace/metric endpoints and no development allowance. Default wiring must send both, with truthful failed/dropped accounting; audit WAL remains separate authority.

11. **Acquisition authority.** Before launcher/driver effects create immutable issuer-registered authority with fresh 128-bit lowercase nonce, profile, original revision and locator binding; exclude mutable phase/manifest digests. Exclusively persist/fsync custody before driver invocation; pass expected generation for create/verify/reset/destroy. Track launcher-state, driver-local partial, published driver, worker and retirement acquisitions separately. A locked root-isolated driver-local owner retains directory device/inode+nonce, durable intent and exact subordinate QEMU/network/disk/key acquisitions. It alone settles partial acquisition; final removal requires exact inventory and proven subordinate retirement. Foreign/extra state stays sticky `cleanup-required`.

   Parent rollback and outer smoke cleanup arm only on exact successful generation-bearing acquisition receipts. Failure, timeout, malformed/lost response, pre-existing state, sentinel discovery or mutable phase grants no parent destroy authority. Remove broad EXIT/name-based cleanup and manifest-absent discovery deletion. Successful destroy consumes capability before reporting. 12. **Bounded KVM verification commands.** Every admitted guest invocation in driver, smoke, and conformance—including discarded-output readiness/verify/reset probes—uses one host-owned fixed-ID argv helper. No direct `run_ssh`, shell command substitution/pipeline or timeout-free bypass remains. Use `Popen(shell=False, start_new_session=True)`, null stdin, selectors/nonblocking raw stdout/stderr, absolute monotonic deadlines and byte caps before decode. Initial stdout caps: boot ID 37 including LF, kernel 65 including LF, host-key scan 4096, ordinary probe 16 KiB; stderr 4 KiB; probe 5–15 seconds; readiness aggregate 120 seconds. Cap+1, cancellation, timeout, malformed bytes, incomplete EOF or truncation flags fail. Retain child identity/pidfd before reap and settle the exact process group and descendants with bounded TERM/KILL/reap; uncertain local/remote retirement makes the VM generation unusable. Validate one-LF UUID/kernel grammars, reject NUL/CR/extra records, emit Python canonical JSON and separately bound QMP time/line/aggregate/message count. Externally verify 2 CPUs, 4 GiB, no swap, 128 tasks, quota-backed 32 GiB writable storage and lifetime before adoption; never automatically raise limits.

13. **KVM nonce.** The sentinel is exactly 32 lowercase hex bytes plus LF, regular/single-link/owner-checked/mode `0600`, equal to the independently retained generation. Trusted controls no longer expect empty bytes. Check the caller nonce under lock before effects and echo it in exact create/verify/reset receipts; reject syntactically valid foreign nonces. Preserve QEMU/network journals and retirement owners.
