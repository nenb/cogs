# ADR 0288: Raise batched preflight correction highs

- Status: Accepted
- Date: 2026-09-02
- Accepted by: Nick Byrne through the standing corrected non-AWS instruction

## Context

Repeated authenticated rehearsals exposed that component-local mocks had not exercised complete producer/validator and failure-recovery seams. Dispatch is now frozen while one batched correction adds production-shaped journal, runtime, network, recovery, evidence, custody, and reusable no-mint diagnostic coverage. No-deletion-credit accounting after the first integrated pass is 20,324 deployment, 10,322 retained schema/script, 4,482 workflow, and 35,128 global lines. Physical retained source is 87,214 lines and conservative accounting is 90,484, below the unchanged mandatory 94,000-line hard stop. Integrated production-shaped tests and split-lineage entries bring tracked source to 1,361 files, one above ADR 0287's narrow bound.

The prior 35,000 global correction high is exceeded by 128 lines before completing the split-lineage diagnostic profile. Compressing exact failure matrices or omitting custody checks would recreate the integration-debugging failure mode this correction is intended to stop.

## Decision

Raise the non-transferable correction highs to 22,000 deployment, 11,500 retained schema/script, 5,000 workflow, and 38,000 global lines. Raise the tracked-source cardinality bound to 1,400. Retain the 90,000 preferred target as an explicit advisory and retain the mandatory 94,000 hard stop. The unused margin is not transferable to unrelated work.

This ADR authorizes only local/static implementation, independent review, ordinary CI, and repeatable non-authorizing KVM diagnostics. It authorizes no producer, publisher, formal rehearsal, qualification, evidence promotion, AWS credential, AWS API, provider, OpenTofu, SSM, inventory, campaign, or resource effect.

## Consequences

The advisory preferred target may report false under conservative no-deletion-credit accounting; the hard stop remains mandatory. After integrating all batched seams, audit corrections, and the additive seven-cycle qualification, measured additions are 21,649 deployment, 10,478 retained schema/script, 4,426 workflow, and 36,553 global lines. Physical retained source is 88,629 lines, conservative accounting is 91,907, and tracked source is 1,371 files. Every raised correction high, the tracked-source bound, and the unchanged 94,000 hard stop are satisfied. A fresh formal generation remains required after the complete diagnostic lane and independent audit pass.
