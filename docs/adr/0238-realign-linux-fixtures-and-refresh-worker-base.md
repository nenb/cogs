# ADR 0238: Realign Linux fixtures and refresh the worker base

- Status: Accepted under the owner's explicit standing authorization for all non-AWS prerequisite work
- Date: 2026-08-29

PR CI after the implementation-H freeze exposed stale Linux-only fixtures, not a new provider or qualification observation. Realign those fixtures with already-reviewed production invariants: prepared-runtime presence before terminal input creation, runtime-mount issuance before `RUNTIME_READY`, input retirement at `CONTAINERD_ABSENT`, exact `INPUT_REMOVED`, the active runtime alias, `r`/`t` runtime directories, both accepted containerd sockets, and complete socket-custody maps. Keep synthetic memfd mount normalization test-only. Make the V3 static SSH fixture drain its complete stdin before output so crash cuts exercise the same transport completion required from OpenSSH; regenerate its exact executable and contract identities.

Image scans independently found fixed CVE-2026-14456. Refresh the worker's immutable Debian 13 distroless index to `sha256:4e4fb0ce55fd73901600796ef079a9490369d2515d7da31633a91608c82ca13b`, whose linux/amd64 image contains `libssl3t64` `3.5.7-1~deb13u2`. The Debian 13.6 package repository still serves vulnerable `3.5.6-1~deb13u2` to the non-production insecure driver, so move only that explicitly insecure test image to immutable Debian testing index `sha256:b21cba5194c0cddc19b41045ceebce11b5413ac40bac7f2410c066b5acb28091`. Use the matching immutable `20260829T000000Z` testing snapshot rather than mixing stable packages into that base, and pin its fixed OpenSSL `3.6.3-1`, Expat `2.8.3-1`, util-linux `2.42.2-2`, and OpenJDK 25 `25.0.4+7-1` package set. Do not add an exception.

Split secret-shaped negative-test tokens at source so scanners do not mistake deliberate validator inputs for credentials. When every network-removal effect is already durably recorded before a crash, admit the exact `RUNTIME_ABSENT` terminal revalidation trace rather than requiring a duplicated effect observation. Derive the immutable cycle route only for SSH marker-bearing commands and before command intent, fork, cgroup, release, or other launch effects; unrelated network/runtime observations and recovery derive no route, and late route derivation can no longer turn an already-started observation into `launch-boundary-uncertain`. These corrections grant no qualification, promotion, release, AWS, provider, deployment, or campaign authority. The earlier implementation checkpoint `dfb28c2e8deb7fed90da095c41b4d556c737af97` remains preserved but cannot be the final H after these corrections; the final control observation must target the newly reviewed, merged implementation H.
