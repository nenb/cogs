# ADR 0162: Resume authenticated unleased prelease cleanup

- Status: Accepted under the owner's explicit standing authorization for all non-AWS prerequisite work
- Date: 2026-08-24

A native cleanup observation was interrupted after every candidate entry and candidate artifact had been removed but before operation retirement. No `leased` record had ever existed. The sealed unadmitted route accepted only terminal `retired`, so it could not invoke the builder's existing exact resumable cleanup for this valid prelease prefix.

For a journal-absent operation binding with no rootfs lease, ordinary release, or prestage authorization, accept an authenticated rootfs ledger in any non-release legal prelease phase only when its source approval matches the fixed source and its state names are exactly fixed infrastructure plus the ledger and at most its token-derived operation directory. Close the read-only cross-owner view, invoke ordinary builder recovery, settle the prestage grant, and prove fixed-idle rootfs state. The builder remains the sole mutation owner and retains all per-phase generation, ledger, fsync, and cleanup checks.

Leased state still requires the distinct durable prestage authorization route. Foreign names, operation journals, coordinates, source drift, or release phases remain preserved failures. No retry, evidence, AWS, provider, deployment, promotion, or release authority follows.
