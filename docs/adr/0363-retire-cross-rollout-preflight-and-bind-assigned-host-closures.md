# ADR 0363: Retire the cross-rollout preflight and bind assigned host closures — Accepted for corrective H; G and Q remain unset until their protected transitions complete. Protected Q `4ffdeb435cc8cd053d47ab173b942ec0f99cd3b4` passed exact-main checks, but sole attempt-one mixed preflight `35822851712` failed before preparation. Its authenticated `ubuntu24` `20260907.300.1` runner differed from static observation `35811001315` on `20260920.314.1`; exact ambient ELF bytes were therefore not portable across the authenticated rollout. The run is terminal and supplies no qualification or AWS authority.
1. Add byte-preserving retirement V6, retire the complete H/G/Q generation and its evidence, and reallocate the unchanged 23,950-line tranche to exact observed task totals 8,430/5,049/6,195/267/4,009; no global, byte, file, or source limit rises. After official release/tag authentication, derive all five ambient host-tool closures; same-image observations remain byte-equal to static control.
2. Compare the canonical package before mutation, retain and recheck one admitted descriptor generation for every closure object, regenerate it under root, and freeze it through a root-owned mode-0700 transaction directory named by the complete package digest before publishing the sole mode-0400 link. This binds H, G, control, run, attempt, ordinal, assigned image, and static image; exact transaction ownership permits deterministic cleanup of empty, partial, or two-link interrupted publication while foreign or differently bound state is preserved and rejected. Local admission consumes the package only for host-path roles; staged-runtime and Kata contracts remain static-control bytes, and routes without it retain existing behavior.
3. Preserve it in every successful cycle artifact, bind its SHA-256 into the artifact name, validate authenticated API custody/readback/aggregation, and delete live custody only when identity and digest are unchanged. Mixed authenticated official releases are admissible; malformed, changed, same-image-divergent, missing-evidence, failed, retried, or residue-bearing observations are not. The protected squash becomes replacement H only after required checks; later governance-only and direct-child updates may record exact H/G/static/Q and authorize only the producer, publisher, static observation, mixed preflight, and seven-runner qualification sequence. Nothing here authorizes AWS roles, planning, approval, provider effects, production R, or Stage 4 promotion. Consequence: the failed generation cannot be retried, stitched, or salvaged; qualification artifacts gain root-published `host-closure.json`, while status V3, package V6, the one-run/two-job R architecture, and authenticated continuation retain their existing meanings.
